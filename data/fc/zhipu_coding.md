## 遇到问题，随时问我

套餐的用量额度限制是多少？

GLM Coding Plan 提供 3 种订阅套餐，满足不同开发场景的需求。为了管理资源并确保所有用户的公平使用，我们执行每 5 小时和每周的使用额度限制。 您可以在 [用量说明](https://docs.bigmodel.cn/cn/coding-plan/overview#%E7%94%A8%E9%87%8F%E8%AF%B4%E6%98%8E) 查看最新套餐的用量额度说明，以选择适合您的套餐。

套餐所支持的模型有哪些？

所有套餐用户均支持 **GLM-5.3、** GLM-5-Turbo、GLM-4.7，查看模型调用 [配置文档](https://docs.bigmodel.cn/cn/coding-plan/latest-model)。

购买 GLM Coding Plan 后如何申请发票？支持哪些发票类型？

您可以进入智谱开放平台的 [发票申请](https://bigmodel.cn/finance-center/bill/invoice/list) 页面，根据页面展示的可开票订单自助申请。发票开具后，会自动发送至您提交的邮箱，您可以通过邮件中的链接下载。

GLM Coding Plan 套餐额度与 API 余额是什么关系？

GLM Coding Plan 套餐额度与标准 API 是相互独立的，分别适用于不同的调用场景。GLM Coding Plan 套餐额度仅限在 [官方支持的编码工具和产品环境](https://docs.bigmodel.cn/cn/coding-plan/tool/others#%E4%B8%80%E3%80%81%E9%80%82%E7%94%A8%E5%B7%A5%E5%85%B7) 中使用；在自建应用、网站、机器人、SaaS 产品或其他场景中需要直接调用标准 API，不能使用套餐额度。

为什么购买了编码套餐还报错“1113余额不足”？为什么购买了编码套餐还扣账号余额？

报错余额不足/扣账号余额的情况可能是由于未满足GLM Coding Plan编码套餐的使用条件：

1\. 只能在我们平台支持的 [特定的工具](https://docs.bigmodel.cn/cn/coding-plan/tool/others) 中使用

2\. 配置特定的baseurl地址才能使用：

**· Claude Code中 baseurl 是：** https://open.bigmodel.cn/api/anthropic

**· Cherry studio配置的 baseurl 是：** https://open.bigmodel.cn/api/coding/paas/v4/

**· Claude Code和Cherry studio之外的工具中 baseurl 是：** https://open.bigmodel.cn/api/coding/paas/v4
